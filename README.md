# Excel Data Analytics Project

## Project Overview

This project focuses on analyzing customer data using Microsoft Excel and creating an interactive dashboard to identify important business insights.

## Tools Used

* Microsoft Excel
* Power Query
* Pivot Tables
* Pivot Charts
* Excel Dashboard

## Project Tasks

* Data cleaning and preprocessing
* Handling missing values
* Removing duplicate records
* Data transformation using Power Query
* Data analysis using Pivot Tables
* KPI creation
* Interactive dashboard development

## Key Analysis

* Customer analysis
* Income analysis
* Spending analysis
* Customer segmentation
* Satisfaction analysis

## Dashboard

The dashboard provides visual insights into the dataset using charts, KPIs, and filters.

## Files

* `Dataset/` – Original dataset
* `Analysis/` – Excel analysis
* `Dashboard/` – Final dashboard
* `Screenshots/` – Dashboard preview
